# 同频 SameHz 推广方案

> 版本 1.0 · 2026-11-25
> 适用阶段：0 到 100 对种子用户

---

## 一、现状诊断

### 1.1 已有资产

| 资产 | 状态 |
| --- | --- |
| 产品 | 可用：本地文件、B站、YouTube、直链，完整同步 + 自动校准 |
| 双语 | 中英文切换 |
| 增长埋点 | 五级漏斗，按天落盘 |
| 增长看板 | `/stats`，30 秒刷新 |
| 邀请海报 | 一键生成 1080×1440 分享图 |
| 素材库 | 12 张封面 + 6 篇配文 + 话术生成器 |
| SEO 基建 | sitemap / robots / JSON-LD / llms.txt / FAQ 内容 |

### 1.2 核心问题

B站视频只有个位数播放。这**不是内容质量问题，是渠道与机制问题**：

1. **B站新号没有初始推荐权重。** 0 粉账号发布后只能进入 50–200 次曝光的测试池，没有完播率和互动就不给二次推荐。
2. **B站用户是来"消费内容"的，不是来"找工具"的。** 工具的发现路径通常是搜索或他人推荐，不在推荐流。
3. **标题打的是自己，不是痛点。** "我做了一个网站"是自述，"异地恋一起看电影别再屏幕共享了"才是搜索词。

### 1.3 竞争现实

真正的对手不是同类产品，而是**屏幕共享**（腾讯会议、Discord、微信视频）。

用户问的第一个问题是"为什么不直接共享屏幕"，答案必须一句话说清：

> 屏幕共享压缩画质、吃上传带宽、要人工对时；同频只传"播到第几秒"，两边都是原片。

## 二、目标与指标

### 2.1 北极星指标

**当日完成「播放 ≥10 分钟」的房间数**（双方入座 + 双方片源就绪 + 一起看了 10 分钟以上）。

不是访问量。因为这个产品一个人用不了，访问量再高，两个人没真的看完一集都等于零。

### 2.2 阶段目标

| 阶段 | 周期 | 目标 | 判定标准 |
| --- | --- | --- | --- |
| 验证 | 第 1–4 周 | 30 对种子情侣 | 累计 `room_activated` ≥ 30 |
| 放大 | 第 5–8 周 | 300 对 | 周新增 ≥ 60，W2 留存 ≥ 25% |
| 规模 | 第 9–12 周 | 1000 对 | 自然增长占比 ≥ 40% |

### 2.3 辅助指标

| 指标 | 位置 | 健康值 |
| --- | --- | --- |
| 邀请转化率（创建 → 双方入座） | `/stats` `seatRate` | > 60% |
| 片源就绪率（入座 → 双方有片源） | `sourceRate` | > 70% |
| 激活率（播放 → 看满 10 分钟） | `activationRate` | > 50% |
| 复制邀请 / 生成海报次数 | `invite_copied` / `invite_shared` | 每房间 ≥ 1.2 |

**诊断规则**：`created` 涨而 `twoSeats` 不涨 = 邀请环节断了，**先修产品，停止推广**。

## 三、渠道策略

### 3.1 优先级排序

| 优先级 | 渠道 | 成本 | 见效 | 说明 |
| --- | --- | --- | --- | --- |
| P0 | 豆瓣小组 | 0 | 慢但持久 | 帖子可挂数年，持续带人 |
| P0 | 小红书评论区 | 0 | 快 | 异地恋笔记更新极快，永远有得回 |
| P0 | 知乎长回答 | 0 | 慢但复利 | 被百度/微信搜一搜收录，长期流量 |
| P1 | 情侣博主置换 | 低 | 中 | 500–5000 粉 UP，免费会员换真实测评 |
| P1 | 搜索引擎自然流量 | 0 | 慢 | 见第五章 |
| P2 | Reddit / Discord | 0 | 中 | 英文市场几乎无竞品 |
| P2 | V2EX / 少数派 | 0 | 中 | 技术社区会主动传播 |
| P3 | 付费投放 | 高 | 快 | **CAC 算清之前不投** |

### 3.2 各渠道具体做法

**豆瓣**：只回帖不发广告帖。在「异地恋怎么一起看电影」「一个人看电影好孤单」类帖子下用 `/reply` 生成的话术回复。每天 1–2 条。

**小红书**：搜「异地恋」按"最新"排序，优先回 24 小时内的新笔记（作者在线，可能回你，曝光翻倍）。每天 ≤10 条。每周自己发 1 条笔记，用 `assets/covers/` 的封面。

**知乎**：写 300–800 字完整回答，不写短评。目标问题是「异地恋可以用什么软件一起看电影」「异地恋怎么一起看电影」。一篇好回答能带一年流量。

**博主置换**：找 500–5000 粉情侣 UP，送永久会员 + 专属邀请码，谈真实体验视频。一次谈 20 个，成 5 个就够。优先纯置换，不行再按转化付费（¥30–80/注册）。

**Reddit**：`r/LongDistance`（40 万成员）。**注意规则**：必须先参与讨论 1–2 周再提产品，否则直接 ban。

### 3.3 绝对不能做

| 行为 | 后果 |
| --- | --- |
| 买粉、买播放 | 数据假 → 算法不再推真实用户 → 账号废 |
| 评论区刷链接 | 举报封号 |
| 自动发帖脚本 | 平台可识别设备指纹，封号只是时间问题 |
| 同一天发 6 条内容 | 判定营销号 |
| 用小号互相捧 | 同 IP 互评会被识别 |

## 四、内容策略

### 4.1 内容公式

**真实使用场景 + 具体痛点 + 诚实自荐。** 不做 AI 生成的情感故事视频（平台降权、转化极差）。

六类可复用选题（素材已备好）：

1. 屏幕共享糊成 PPT 的对比
2. 两台手机同帧对齐的"魔法时刻"
3. 相距千公里看同一帧
4. B站视频也能同步了
5. 不用买两份会员
6. 凌晨的电影夜

### 4.2 标题原则

| 错误示范 | 正确示范 |
| --- | --- |
| 我做了一个同步看电影的网站 | 异地恋一起看电影，别再屏幕共享了 |
| 同频上线啦 | 两个人看同一部电影，进度差 0.01 秒 |
| 一个 WebSocket 同步项目 | 异地恋看电影，不用买两份会员 |

**标题里必须出现用户会搜的词**：异地恋、一起看电影、同步播放。

### 4.3 发布节奏

| 周 | 内容 | 平台 |
| --- | --- | --- |
| 1 | 痛点 + 新功能 | 小红书优先，B站同步 |
| 2 | 对比 + 情感 | 小红书 + B站 |
| 3 | 省钱 + 故事 | 小红书 |

一天一条，连续比爆发有效。

## 五、搜索引擎收录

### 5.1 已完成的站点改造

| 项目 | 内容 |
| --- | --- |
| `robots.txt` | 允许抓取首页，禁止 `/room/`、`/api/`、`/stats`、`/reply`；显式允许 GPTBot、PerplexityBot、ClaudeBot、OAI-SearchBot、Google-Extended |
| `sitemap.xml` | 动态生成，带 `lastmod` 与中英文 `hreflang` |
| `title` | 「异地恋一起看电影 \| 同频 SameHz · 两个人同步播放同一部电影」 |
| `description` | 含核心关键词、卖点、免费声明 |
| `canonical` | 指向正式域名 |
| Open Graph | 完整 og/twitter 卡片 + 1200×630 分享图 |
| JSON-LD | `WebSite` + `WebApplication`（含免费 Offer、功能清单）+ `FAQPage`（6 问） |
| FAQ 可见内容 | 页面底部真实可读的 6 组问答 + 三种方案对比表 |
| 房间页 | `noindex`（私密页面不能被收录） |

**关键原则：结构化数据必须与页面可见内容完全一致**，否则会被判定作弊。测试 `npm run test:seo` 会校验这一点。

### 5.2 需要你手动做的（约 30 分钟，一次）

按顺序做，**Bing 一定不能跳过**（原因见第六章）：

1. **Bing Webmaster Tools**（`bing.com/webmasters`）
   - 添加站点 `samehz.onrender.com`
   - 验证方式选「HTML 元标记」，把给出的 `<meta>` 加到 `public/index.html` 的 `<head>` 里
   - 提交 sitemap：`https://samehz.onrender.com/sitemap.xml`
   - 用 "URL 提交" 手动提交首页

2. **Google Search Console**（`search.google.com/search-console`）
   - 添加「网址前缀」资源
   - 验证方式同上（HTML 标记）
   - 提交 sitemap
   - 用「网址检查」→ 请求编入索引

3. **百度搜索资源平台**（`ziyuan.baidu.com`）
   - 验证站点（同样用 meta 标签）
   - 提交 sitemap
   - 使用「快速收录」提交首页（每天有配额）

4. **IndexNow**（可选但很快）
   - Bing、Yandex 支持即时推送，改一行命令就能通知收录

### 5.3 收录时间预期

| 事项 | 时间 |
| --- | --- |
| Bing 收录首页 | 1–7 天 |
| Google 收录首页 | 3–14 天 |
| 百度收录首页 | 1–4 周 |
| 关键词进入前 3 页 | 1–3 个月，依赖外链 |
| 关键词进入第 1 页 | 3–6 个月以上 |

**坦白说**：`samehz.onrender.com` 这类平台子域名权重极低，靠它排到「异地恋一起看电影」第一页很难。**建议尽快绑定自定义域名**（如 `samehz.com`），SEO 效果会好一个量级。

### 5.4 涨权重的唯一方法：外链

搜索引擎排名的核心是「有多少可信网站提到你」。所以：

- 知乎回答里带网址（nofollow 但也有价值）
- 豆瓣帖子提一句
- Reddit 帖子
- V2EX 分享贴
- 任何独立博客/公众号提到

**10 个真实提及 > 100 条自吹。**

## 六、让 AI 搜索推荐我们

### 6.1 先理解机制

AI 搜索不是靠"提交"，是靠**检索**。当用户问「异地恋怎么一起看电影」，AI 会：

1. 把问题改写成搜索词
2. 调用搜索引擎 API 拿结果（**ChatGPT 用 Bing，Perplexity 用 Bing + 自有索引，Google AI Overviews 用 Google 索引**）
3. 抓取排名靠前的页面内容
4. 摘录并引用

所以：**AI 推荐的前提是被搜索引擎收录 + 内容能被直接摘录 + 有第三方佐证。**

训练数据这条路走不通——模型的知识是几个月前的，改不了。能改的只有检索层。

### 6.2 已完成的 GEO 改造

| 项目 | 作用 |
| --- | --- |
| `llms.txt` | 给 AI 爬虫的站点说明，含一句话定义、支持片源、不支持场景、FAQ |
| `robots.txt` 显式允许 GPTBot / PerplexityBot / ClaudeBot / OAI-SearchBot | 避免被误拦 |
| FAQ 结构化 + 可见问答 | AI 能直接摘录成答案 |
| 一句话实体定义 | "同频是一个免费的网页工具，让异地恋的两个人同步观看同一部电影" —— 出现在 title、description、llms.txt、JSON-LD 中，让 AI 能识别这是什么 |
| 对比表 | 回答"和屏幕共享有什么不同"这类问题时的最佳摘录源 |

### 6.3 让 AI 更愿意推荐的三件事

**第一，写能被整段摘录的句子。** AI 喜欢事实性、独立成句、不需要上下文的内容。例如：

> 同频是免费的，无需注册，支持 B站、YouTube 和本地视频，视频不上传服务器。

这句话可以直接被引用。而"我们致力于为用户打造极致体验"这类空话不会被摘录。

**第二，让第三方替你说话。** AI 在多个来源都看到同一件事时才会确信。所以要在知乎、豆瓣、Reddit 上**被别人讨论**，而不只是自己说。

优先做这几件事：
- 在知乎问题下写高质量回答（AI 大量引用知乎）
- Reddit `r/LongDistance` 发帖（AI 引用 Reddit 频率极高）
- 出现在"异地恋必备工具"类清单文章里（联系博主写进合集）

**第三，保持页面更新。** `sitemap` 的 `lastmod` 会更新，AI 爬虫更愿意重访活跃站点。

### 6.4 怎么验证 AI 有没有推荐你

每周做一次，记录结果：

| 平台 | 测试问题 |
| --- | --- |
| ChatGPT | 异地恋怎么一起看电影 |
| Perplexity | 两个人怎么同步看同一部电影 |
| Kimi / 豆包 | 异地恋看电影有什么工具 |
| Google（AI Overviews） | 异地恋一起看电影 工具 |

初期一定不会出现，这很正常。按第二章和 6.3 的步骤做，通常 **1–3 个月**后开始出现在回答的"参考来源"里。

### 6.5 关于 AI 的诚实预期

- **短期内 AI 不会推荐一个新网站。** 模型和检索系统都倾向于引用已有的、被多次提到的内容。
- **不要相信任何"AI 排名优化"的付费服务。** 目前这个领域没有可靠的外部手段，能做的就是上面那些。
- **真正的杠杆是第三方提及量。** 一个被 20 个真实帖子提到的网站，比任何技术优化都有效。
